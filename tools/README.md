# tools/ — скрипты генерации и проверки ресурсов

Все скрипты на Python 3 (только стандартная библиотека, кроме `gen_textures.py` — ему нужен Pillow).
Запускать из корня проекта.

| Скрипт | Что делает | Пишет в |
|---|---|---|
| `gen_all.py` | запускает всё по порядку и в конце проверку | — |
| `gen_lang_models.py` | переводы (ru_ru + en_us), модели предметов/блоков, blockstates | `assets/rpgmod/lang`, `models`, `blockstates` |
| `gen_textures.py` | генерирует заглушки-текстуры 16×16, скины мобов, слои брони | `assets/rpgmod/textures` |
| `gen_structures.py` | собирает `.nbt`-шаблоны: подземный лабиринт, замок, башня, постройки деревни | `data/rpgmod/structures` |
| `patch_worldgen.py` | переработка генерации мира: высота 512, крупные биомы/океаны, отключение ванильных «данжей» | `data/minecraft/...` (оверрайды) |
| `gen_data.py` | типы урона, лут-таблицы сундуков, глобальные лут-модификаторы, структуры/пулы/наборы, теги | `data/rpgmod/...`, `data/forge/...` |
| `validate_assets.py` | проверка целостности: модели, текстуры, ключи переводов, ссылки в JSON, шаблоны | — (только отчёт, код возврата 1 при проблемах) |

## Типичные задачи

```bash
# пересобрать всё после правок
python3 tools/gen_all.py

# только проверка (запускается в CI перед сборкой)
python3 tools/validate_assets.py

# изменить высоту мира / масштаб биомов -> константы в начале patch_worldgen.py
# изменить частоту данжей            -> числа в gen_data.py (структуры, spacing/separation)
# изменить состав лута               -> gen_data.py, функция gen_loot_tables()
# добавить новый предмет             -> ModItems.java + списки в gen_lang_models.py
```

## Важно

* **Текстуры — заглушки**, сгенерированные программно. Замените PNG-файлы своим артом: имена уже
  совпадают с тем, что ожидает игра, код менять не надо.
* **Шаблоны структур `.nbt`** открываются в игре структурным блоком (Structure Block → Load),
  их можно отредактировать в игре и положить обратно в `data/rpgmod/structures/`.
* `patch_worldgen.py` скачивает ванильные JSON'ы 1.20.1 из `misode/mcmeta` (в кэш `tools/.cache/`,
  он не коммитится) и патчит их. Без интернета скрипт не запустится — готовые файлы уже в репозитории.
